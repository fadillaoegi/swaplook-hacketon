# MVP scope

One synthetic boutique, 12 tops, sizes XS–XL, USD cents. Catalog images are openly licensed Wikimedia Commons photographs (docs/CATALOG-CREDITS.md) with fictional names, prices and stock; the same files are the YouCam garment references. Original SVG illustrations remain only as simulator fixtures.

Shopper: unavailable variant → budget and required color/material → at most three valid alternatives with metadata reasons → explicitly labeled simulator preview or consented upload for configured YouCam → comparison → transactional stock/price recheck → persisted choice or rejection.

Merchant: authenticated inventory changes and demo choice/rejection summary. All current sessions/events are demo data, including tests; genuine research observations will use a separate study dataset.

No marketplace aggregation, scraping, real checkout, inventory reservation, native app, Shopify plugin, skin analysis or extra LLM. An illustration is not a fit guarantee. Provider failures remain visible.
