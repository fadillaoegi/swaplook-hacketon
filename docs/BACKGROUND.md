# Why SwapLook

**Find an in-stock alternative. See it on you.**

A shopper wants a top, but their size is unavailable. Choosing a substitute requires checking size availability, price, catalog attributes and appearance. A small boutique may struggle to support this decision consistently over chat.

SwapLook tests whether a shortlist that respects shopper constraints, followed by a visual preview, helps shoppers choose an alternative. This is a hypothesis: there are no customer interviews, conversion results, recovered sales or return-reduction evidence yet.

Initial users are shoppers on mobile browsers and one boutique owner on desktop. The working name has not been checked for trademark/domain availability. This implementation follows the 17 October 2026 research and handoff in the sibling research folder. The handoff's selected name and implementation instructions supersede the earlier research's undecided status.
