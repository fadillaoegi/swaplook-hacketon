# SwapLook identity

The original mark combines two clothing labels pointing in opposite directions: an alternative found, and a second look. The compact silhouette also suggests an S. The wordmark uses custom vector lettering and needs no external font.

- Primary indigo: `#4F46E5`; light indigo: `#C7D2FE`.
- Wordmark ink: `#202232`; main background: white.
- Keep at least one quarter of the icon's width clear around the logo. Preserve proportions.
- Use the horizontal logo in the app header/footer and documents; use the square icon for browser tabs and app shortcuts.

Assets are in `swaplook_FE/public/brand`: SVG horizontal/monochrome logos, SVG icon, transparent PNG logo, and 192/512/1024 px PNG icons. Browser assets are `favicon.svg`, multi-resolution `favicon.ico` (16/32/48/64 px), and `apple-touch-icon.png` (180 px).

Regenerate exports with `python3 scripts/generate_brand.py` (ImageMagick required). These project-authored assets are covered by the project's MIT license.
